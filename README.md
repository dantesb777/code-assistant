# 🤖 Code Assistant Bot

Bot de Discord que analiza código automáticamente usando Inteligencia Artificial.

## ✨ Características

- 🔍 **Análisis de código** en Python, JavaScript, TypeScript y Java
-  **Detección de bugs** y sugerencias de mejora
- 📊 **Score de calidad** de 0-10
-  **Disponible 24/7** en la nube
- 🇪🇸 **Respuestas en español**

## ️ Tecnologías

- **Python 3.12** - Lenguaje principal
- **Discord.py** - Framework para bots de Discord
- **Groq API** - IA de alta velocidad (Llama/Qwen)
- **GitHub API** - Lectura de repositorios
- **Flask** - Servidor web para keep-alive
- **Render** - Hosting en la nube

## 📋 Comandos

| Comando | Descripción |
|---------|-------------|
| `!hola` | Verifica que el bot está activo |
| `!analizar` | Analiza el repositorio actual |
| `!ping` | Muestra la latencia del bot |
| `!ayuda` | Muestra todos los comandos disponibles |
